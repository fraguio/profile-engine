# Etiquetas de triage

Las skills utilizan cinco roles canónicos de triage. Este archivo relaciona esos roles con las etiquetas reales del gestor de issues de este repositorio.

| Etiqueta en mattpocock/skills | Etiqueta en nuestro gestor | Significado                                      |
| ----------------------------- | -------------------------- | ------------------------------------------------ |
| `needs-triage`                | `needs-triage`             | Un mantenedor debe evaluar este issue             |
| `needs-info`                  | `needs-info`               | A la espera de más información del autor          |
| `ready-for-agent`             | `ready-for-agent`          | Completamente especificado y listo para un agente |
| `ready-for-human`             | `ready-for-human`          | Requiere implementación humana                    |
| `wontfix`                     | `wontfix`                  | No se llevará a cabo                              |

Cuando una skill mencione un rol, por ejemplo, «aplica la etiqueta de triage para trabajo listo para un agente», utiliza la etiqueta correspondiente de esta tabla.

Edita la columna central para adaptarla al vocabulario que utilices realmente.
